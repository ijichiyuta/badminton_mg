# ADR-0003 同期は一方向・全量スナップショットにする

日付: 2026-09-13 / 状態: 採択

## 背景
オフラインファーストかつ運営者が1人であるため、書き込みを行う端末は1台に限られる。

## 決定
同期は運営端末からサーバへの一方向とし、大会データの全量スナップショットを送信する。
差分同期、双方向同期、競合解決は実装しない。

## 理由
- 書き手が1人なので、そもそも競合が発生しない
- 大会1つ分のデータは数百 KB に収まるため、全量送信で性能上の問題がない
- 冪等な設計になり、リトライが安全になる
- サーバがロジックを持たないため、障害点が減る

## 結果
- 実装コストが大幅に下がる
- v2 で複数端末対応する際は、同期層の作り直しが必要になる。これは許容する
- サーバ側のデータは常に上書きされるため、サーバを編集の起点にできない

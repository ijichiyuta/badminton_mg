# ADR-0004 PWA とし、ネイティブアプリにしない

日付: 2026-09-13 / 状態: 採択

## 背景
運営者が当日持ち込む端末は、協会の共用 PC、私物のタブレット、スマートフォンなど一定しない。

## 決定
ブラウザで動作する PWA として実装する。ネイティブアプリ化しない。

## 理由
- 電波がない会場ではアプリストアからダウンロードできない。ブラウザなら事前に開いておけばキャッシュから起動する
- 協会の共用 PC はインストール権限がない場合がある
- Windows / macOS / iPadOS / Android を1つのコードベースで賄える
- 審査を通さずに即日修正できる。大会前日に不具合が見つかっても間に合う

## 結果
- OS のネイティブ機能（バックグラウンド処理、ローカルネットワークのサーバ機能）が使えない
- 会場内 LAN での閲覧配信を実装する場合は、別の手段が必要になる
- ブラウザのストレージ消去でデータが失われるリスクがあり、バックアップ促しで緩和する

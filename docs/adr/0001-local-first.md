# ADR-0001 ローカルファーストにする

日付: 2026-09-13 / 状態: 採択

## 背景
体育館の電波状況は会場によって異なり、事前に保証できない。
また運営者は1人であり、通信障害の切り分けに人手を割けない。

## 決定
**端末内のデータを正とする。** サーバはバックアップと閲覧ページ配信のみを担う。
ネットワークが存在しない状態で、結果入力から順位確定、印刷までの全経路が動作する。

## 理由
- 電波の有無が大会の成否を左右する設計は、現場で受け入れられない
- サーバ障害が大会を止めないため、運用責任が軽くなる
- 1人運用のため、複数端末間の整合性を考える必要がない

## 結果
- 複数端末でのリアルタイム分担入力は v1 では不可能になる
- 端末が1台壊れた場合に大会が止まるリスクを、バックアップとエクスポートで緩和する必要がある
- 将来 v2 で複数端末対応する際は、同期層の作り直しが必要

# 未確定事項

回答方法：各質問の `A:` 行に直接書き込む。番号だけで返してもらってもよい。

優先度の意味：
- **必須** … これが埋まらないと v1 の設計が確定しない
- 重要 … 実装中に判明しても致命的ではないが、早いほど手戻りが減る
- 後回し … v2 以降で決めればよい

## E. 順位決定ルール（最重要）

**ここが本システムの中核であり、現場で最も揉める箇所。** 要項の原文が手に入るなら、E群はそれで一括して埋まる。

> **2026-09-13 更新：原文が手に入った。しかし穴がある。**
> 「勝敗数 → ゲーム勝率 → 得失点差」までは確定した。
> 一方で **3者以上の同率・棄権・決着不能時の規定が一切書かれていない。**
> 各ブロック1位・2位を表彰するため、2位を必ず決める必要があり、同率処理は毎回起きる。
> **E-9 が最重要の未回答項目になった。**

- **E-1** 【必須】大会要項に書かれている順位決定方法の**原文**。写真可。一字一句が重要。
  **A: 組み合わせ表の原文：**「リーグ戦にて勝敗数が同じ場合はゲーム勝率にて、ゲーム勝率が同じ場合は得失点差にて順位を決定します。」****
- **E-2** 【必須】判定の優先順位。（勝利数 → 直接対決 → ゲーム率 → ポイント率、など）
  **A: **勝敗数 → ゲーム勝率 → 得失点差****
- **E-3** 【必須】「率」で判定するか「差」で判定するか。（取得ゲーム率 vs 得失ゲーム差）
  **A: **ゲームは「率」（ゲーム勝率）、ポイントは「差」（得失点差）。混在している****
- **E-4** 【必須】3者以上が同率になった場合の規定は要項に書かれているか。書かれている場合その原文。
  **A: **書かれていない。** 3者以上の同率について要項にも組み合わせ表にも規定がない。**各ブロック1位・2位を表彰するため、同率処理は毎回発生する****
- **E-5** 【必須】棄権者が出た場合の扱い。以下のどれか。
  - 棄権試合を「基準点-0」として記録する（15点制なら 15-0, 15-0）

  - 棄権者と対戦した相手の成績からも当該試合を削除する
  - その他
  A:

  A:
- **E-7** 重要 リーグ戦で、勝敗が決まっても全試合を消化するか。（ゲーム率に影響する）

## F. 採点方式

**国内大会は 3ゲーム×15点制へ移行する予定。** 既定値は15点制にしたが、
対象大会の次回がどちらで開催されるかは要確認。

- **F-1** 【必須】対象大会の次回開催は **15点3ゲーム制か、21点3ゲーム制か**。
  移行予定があるなら、いつからか。
  **A: **15点制。移行予定ではなく、すでに実運用されている**（2026-09-06 の大会で使用）**
- **F-2** 【必須】級別・年齢別で採点方式が混在するか。（例：C級だけ1ゲーム制）
  A:
- **F-3** 【必須】15点制の**決着上限点**。20-20 のあと21点で決着か、2点差がつくまで無制限か。
  **A: **大会ごとに違う。愛知の個人戦は最大17、全国団体戦は最大21、5チームリーグは打ち切り（延長なし）。固定値にできない****
- **F-4** 重要 15点制のインターバル。8点で60秒か、インターバルなしか。
  **A: 全国協議会の告知では**8点**（11点から短縮）**
- **F-5** 重要 21点制を併用する場合の決着上限点。30点か、上限なしか。
  A:
- **F-6** 重要 **11点以下・時間制などの短縮運用**があるか。（11点1ゲーム、10分1本勝負など）
  ある場合、どのステージで使うか。
  **A: たまにある。使える状態にしておく。ただし普段使わない設定が入力の邪魔をしないこと。**
- **F-7** 後回し ゲーム間インターバル（2分）の運用。進行管理に使うか。
  A:
- **F-8** 【必須】**予選と決勝で採点方式を変えているか。**
  （例：予選リーグは21点1ゲーム、決勝トーナメントは21点3ゲーム）
  ローカル大会で最も多い運用のため、ここが確定するとステージ構成プリセットが決まる。
  **A: 変える大会も、変えない大会もある。両方に対応する。**
- **F-9** 重要 種目・級・年齢区分ごとに採点方式が違う場合、その対応表。
  **A: 違う大会も、揃っている大会もある。両方に対応する。**
- **F-10** 重要 予選リーグの成績を決勝リーグへ持ち越す運用があるか。
  ある場合、予選と決勝で採点方式は同一か。**異なると率系の順位決定が破綻する**。
  **A: 持ち越す大会も、持ち越さない大会もある。両方に対応する。**
  → 採点方式が異なる場合でも成立するよう、**持ち越しの粒度**（勝敗のみ／成績すべて）を分けて対応する（P-19）。
